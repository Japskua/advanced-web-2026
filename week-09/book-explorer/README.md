# Book Explorer (week 9)

Searches the Open Library API as you type: custom hooks (`useDebouncedValue`, `useBookSearch`, `useLocalStorage`), cancellation, pagination and `memo`/`useCallback`. Front-end only.

**Lecture notes:** [week-09/README.md](../README.md) explains every concept in this project step by step.

## Run it

```bash
bun install
bun run dev
```

Runs at http://localhost:5173.

## Scripts

| Command | What it does |
| ------- | ------------ |
| `bun run dev` | Dev server with hot reload |
| `bun run build` | Production build into `dist/` |
| `bun run typecheck` | Type-check with `tsc` (Bun runs TypeScript but never checks it) |
