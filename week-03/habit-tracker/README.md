# Habit Tracker (week 3)

A first React app: components, props, state, immutable updates and an optional `useMemo` progress bar. Bundled and served by Bun; no back-end.

**Lecture notes:** [week-03/README.md](../README.md) explains every concept in this project step by step.

## Run it

```bash
bun install
bun run dev
```

Runs at http://localhost:5173.

## Scripts

| Command | What it does |
| ------- | ------------ |
| `bun run dev` | Dev server with hot reload |
| `bun run build` | Production build into `dist/` |
| `bun run typecheck` | Type-check with `tsc` (Bun runs TypeScript but never checks it) |
